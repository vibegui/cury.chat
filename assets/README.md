# assets/

Brand assets for the Cury bot — used by the studio MCP listing, the
README, and any future landing page.

| File | Purpose | Format |
|---|---|---|
| `icon.png` | Bot avatar — uploaded to deco studio's "Add MCP Server" image field. Also used as the favicon source. | 1291×1276 RGBA PNG, brand green background (`#0a4d3c`) |

## When forking

Replace `icon.png` with your bot's avatar. Studio re-fetches the image you
upload at registration — you don't have to redeploy the worker.
